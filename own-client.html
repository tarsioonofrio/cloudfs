Create your own OAuth client

One time, about two minutes. This is the same model rclone uses.

GDisk ships without Google credentials. Each person creates their own “Desktop app” OAuth client, so there is no shared quota, no dependency on anyone else, and no “unverified app” review standing between you and your own files.

Steps

  1. Open Google Cloud Console → New project and create a project (any name).
  2. Open the Google Drive API page and click Enable.
  3. Open Google Auth Platform → Get started. App name: anything that does not contain “Google” or “Drive”. Audience: External. Add your e-mail as contact.
  4. Under Audience, click Publish app. Without this, Google expires the token every 7 days. You do not need to go through verification for personal use: the “unverified app” warning appears once at sign-in (Advanced → Go to … (unsafe)).
  5. Under Clients, click Create client and choose Desktop app.
  6. Copy the Client ID and the Client secret.

Sign in

In the GDisk window, click Configure and paste both values. Or, in a terminal:

gdisk login

Or pass them directly: gdisk login --client-id ID --client-secret SECRET. They are saved to ~/.config/gdrived/config.toml, readable only by you.

Questions

Is it safe to keep the secret in a file? For desktop apps Google treats the client secret as non-confidential (it ships inside every such app). The file is written with owner-only permissions.

The token expired (invalid_grant). Run gdisk login again. If it happens every 7 days, the app is still in “Testing”: go back to step 4.
